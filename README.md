# Protótipo de Estacionamento do Campus

Este protótipo em linha de comando simula a consulta e filtragem de vagas no campus.

## Requisitos Cobertos
- **R1:** Listagem geral de vagas (categorias exclusivas: pcd, idoso, ru, derac, coberta, geral).
- **R2:** Filtro de vagas por disponibilidade e por categoria especifica.

## Como Executar
1. Execute o comando: `python main.py`
